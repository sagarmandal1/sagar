# Enhanced User Credit Management System

একটি সম্পূর্ণ ব্যবহারকারী ব্যবস্থাপনা ও ক্রেডিট পরিচালনা সিস্টেম বাংলা ইন্টারফেস সহ।

## বৈশিষ্ট্যসমূহ

### ✨ উন্নত ক্রেডিট ম্যানেজমেন্ট
- **দ্রুত ব্যবহারকারী অনুসন্ধান**: ড্রপডাউন থেকে সহজে ইউজার নির্বাচন
- **তাৎক্ষণিক পরিমাণ নির্বাচন**: ৳৫০, ৳১০০, ৳২০০, ৳৫০০, ৳১০০০ এর বোতাম
- **লাইভ API গণনা**: পরিমাণের ভিত্তিতে API কল সংখ্যা দেখান (১ টাকা = ১০ API কল)
- **সাম্প্রতিক কার্যক্রম**: শেষ ১০টি ক্রেডিট লেনদেন দেখান
- **আজকের সারসংক্ষেপ**: দৈনিক লেনদেন ও মোট পরিমাণ

### 👥 ইউজার ম্যানেজমেন্ট
- সৃষ্টি, সম্পাদনা, মুছে ফেলা ও তালিকা প্রদর্শন
- ইমেইল ভ্যালিডেশন ও ডুপ্লিকেট চেক
- ব্যালেন্স ট্র্যাকিং ও আপডেট
- কার্ড ভিউতে সুন্দর ব্যবহারকারী প্রদর্শন

### 🎨 ইউজার ইন্টারফেস
- **পূর্ণ বাংলা ভাষা সমর্থন** Noto Sans Bengali ফন্ট সহ
- **Bootstrap 5** দিয়ে সম্পূর্ণ রেসপন্সিভ ডিজাইন
- **Font Awesome আইকন** সুন্দর ভিজ্যুয়াল এলিমেন্টের জন্য
- **গ্রেডিয়েন্ট ব্যাকগ্রাউন্ড** আকর্ষণীয় লুকের জন্য
- **অ্যানিমেশন ও ট্রানজিশন** মসৃণ ব্যবহারের অভিজ্ঞতার জন্য

### 🔒 নিরাপত্তা ও ভ্যালিডেশন
- PHP PDO দিয়ে SQL ইনজেকশন প্রতিরোধ
- ইনপুট স্যানিটাইজেশন ও ভ্যালিডেশন
- AJAX এর মাধ্যমে নিশ্চিতকরণ ডায়ালগ
- সেশন ভিত্তিক বার্তা সিস্টেম

## সেটআপ নির্দেশাবলী

### ১. সিস্টেমের প্রয়োজনীয়তা
- PHP 7.4 বা তার উপরে
- MySQL 5.7 বা তার উপরে
- Apache/Nginx ওয়েব সার্ভার

### ২. ডাটাবেস সেটআপ
```sql
-- database_setup.sql ফাইলটি MySQL এ রান করুন
mysql -u root -p < database_setup.sql
```

### ৩. ডাটাবেস কনফিগারেশন
`users.php` ফাইলের উপরের অংশে ডাটাবেস সেটিংস আপডেট করুন:

```php
// Database configuration
$host = 'localhost';          // আপনার ডাটাবেস হোস্ট
$dbname = 'user_management';  // ডাটাবেস নাম
$username = 'root';           // ডাটাবেস ইউজারনেম
$password = '';               // ডাটাবেস পাসওয়ার্ড
```

### ৪. ওয়েব সার্ভার সেটআপ
ফাইলগুলো আপনার ওয়েব রুট ডিরেক্টরিতে রাখুন এবং `users.php` এ ব্রাউজ করুন।

## ডাটাবেস স্কিমা

### `users` টেবিল
- `id`: প্রাইমারি কী
- `name`: ইউজারের নাম
- `email`: ইউনিক ইমেইল ঠিকানা
- `phone`: ফোন নম্বর (ঐচ্ছিক)
- `balance`: বর্তমান ব্যালেন্স
- `created_at`, `updated_at`: টাইমস্ট্যাম্প

### `credit_transactions` টেবিল
- `id`: প্রাইমারি কী
- `user_id`: ইউজার রেফারেন্স
- `amount`: ক্রেডিট পরিমাণ
- `note`: লেনদেন নোট
- `created_at`: লেনদেনের সময়

## API কল গণনা
সিস্টেমটি ১ টাকা = ১০ API কল হিসাবে গণনা করে। এটি `users.php` এর জাভাস্ক্রিপ্ট অংশে পরিবর্তন করা যায়।

## কাস্টমাইজেশন

### রঙ ও থিম পরিবর্তন
CSS ভেরিয়েবল ও গ্রেডিয়েন্ট কালার পরিবর্তন করে থিম কাস্টমাইজ করুন।

### API কল রেট পরিবর্তন
জাভাস্ক্রিপ্টে `const calls = Math.floor(amount * 10);` এই লাইনে ১০ এর বদলে আপনার পছন্দের রেট দিন।

### ভাষা পরিবর্তন
সমস্ত বাংলা টেক্সট HTML এ লেখা আছে, সহজেই অন্য ভাষায় পরিবর্তন করা যায়।
